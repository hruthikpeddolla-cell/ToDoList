# To-Do List Web Application

A simple and interactive To-Do List application developed to help users organize daily tasks, track completed activities, and manage their work efficiently.

## Features

- **Add Tasks:** Create new tasks quickly.
- **View Tasks:** Display all added tasks.
- **Complete Tasks:** Mark tasks as completed.
- **Delete Tasks:** Remove tasks that are no longer needed.
- **Interactive Interface:** Simple and user-friendly design.
- **Responsive Design:** Works on desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Getting Started

### Prerequisites

- A web browser such as Google Chrome.
- Visual Studio Code (recommended).

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project Folder

```bash
cd ToDoList
```

### Step 3: Run the Application

Open `index.html` directly in your browser.

Alternatively, open the project in VS Code and use the Live Server extension to preview the application.

## How to Use

1. Open the To-Do List application.
2. Enter a task in the input field.
3. Click the Add button to create the task.
4. Mark a task as completed when you finish it.
5. Delete tasks that you no longer need.
